### Theme 5: Agent cost needs a denominator (cost per outcome becomes a control)
- **Thesis:** Agent spend is moving from FinOps into the agent control loop (caps, pause, cost graded against outcome). Observability owns the numerator (tokens); the denominator (incident resolved, change succeeded) lives in ITSM. Whoever joins the two owns the agent budget. Counter: vendors shift to bundled/outcome pricing (which Gartner says avoids the overrun), making per-outcome telemetry a niche.
- **Status:** 📈 Substack-ready as of 2026-11-17 (8 data points as of 11-19). Newest angle 11-19: once the trace is a customer-owned table (BigQuery agent_events, Azure Monitor), cost per outcome is a SQL join; the missing piece is an agent ID on the ITSM ticket. New angle: two competing denominators: Microsoft's "work completed" (task success, satisfaction, assisted hours) vs ITSM's IT outcomes (incident resolved, change succeeded). Still missing: a hard cost-per-resolved-incident number from any vendor.

### Theme 6: The autonomy gap is a verification gap
- **Thesis:** Agents are everywhere in IT ops but few run unsupervised. The bottleneck isn't model capability; it's the human verification step (approvals, review of agent decisions), which nobody records in a reusable way. Whoever turns the human "yes" into a recorded, graded approval (ITSM record + observability trace) owns the path to autonomy. Counter: the numbers are self-reported vendor surveys; verification may drop on its own as models and trust improve.
- **Status:** 📈 Substack-ready (10 data points as of 2026-11-24). Newest angle 11-24: the gate's twin is the undo. Shirudo lets an agent ship a signed kernel-level fix to production; banks want kill switches that find what an agent created. Neither writes an ITSM change record, so nobody owns retiring the agent's change. Newest angle 11-20: the human gate is now a product feature, but each vendor keeps the approval in its own system (git PR, gateway trace, on-call tool), none in ITSM change. Earlier angle: vendors GA the 'propose' half and keep the 'act' half in preview.
- **Data points:**
